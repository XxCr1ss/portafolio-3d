# portafolio-3d

Taller isométrico interactivo de Cristian Cabrera. Proyecto de Diseño de Experiencias Web 3D.

## Desarrollo local

Usa Node 24 (ver `.nvmrc`).

```bash
npm ci
npm run dev
```

```bash
npm run lint
npm run typecheck
npm run build
npm run preview
```

Consulta el [plan del Sprint 1](Backlock/PLAN_IMPLEMENTACION_SPRINT_1.md) y el [backlog](Backlock/PRODUCT_BACKLOG_SPRINT_BACKLOG.md).
